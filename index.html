1. Loop over

Pick the array to loop over: you get one output per item, and inside it the current item is $item. Leave it on the whole document for a single output.

Only include items where…

These fields must not be empty (missing, blank, [] or {} all count as empty).

2. Transform

Output is built once per item. Use $item and $item__field (click a tag on the left to insert it). Any path from the document root also works anywhere, e.g. $steps__step_id; through an array it gives all the values.
Build the output as XML elements. Set repeat to an array (e.g. $item__tool_calls) to emit the element once per entry, named by as (default child); children can use $child and $child__field. Repeating over an object gives one entry per key: $child is the key and $child__value its value (or repeat over $obj__items). Tag names, text and attributes may contain $refs.

Export (optional)
